# Product Roadmap

See [ROADMAP.md](../ROADMAP.md) for the full roadmap.

## MVP Features (2026)

### Must Have (P0)
- [ ] User authentication
- [ ] Machine registration
- [ ] ESP32 sensor ingestion
- [ ] Prediction AI (health score, failure prob, RUL)
- [ ] Real-time dashboard
- [ ] Digital Twin (color-coded 3D model)
- [ ] Factory Assistant (LLM chat)
- [ ] Alert system

### Should Have (P1)
- [ ] Maintenance task management
- [ ] 7-day trend charts
- [ ] Email/SMS alerts
- [ ] Multi-user access

### Nice to Have (P2)
- [ ] Energy monitoring
- [ ] PDF report generation
- [ ] Mobile responsive
